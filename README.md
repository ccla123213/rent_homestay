# Rent Homestay

## Tính năng

- HTML5 semantic
- Responsive (mobile-first): Mobile → Tablet → Desktop
- Flexbox + CSS Grid
- Form HTML5 (search stays)
- Transition / hover effects
- Accessibility cơ bản (aria-label, focus, semantic tags)
- Clean code

## Cấu trúc

```
localhost-website/
├── index.html
├── styles.css
└── README.md
```

## Chạy local

Mở `index.html` bằng trình duyệt hoặc dùng live server.
